# 远程画面 · 全屏工作台怎么用

在手机上看着电脑屏幕操作电脑：点画面就是点电脑，旁边有语音、键鼠、常用按钮。

## 打开

1. 电脑上的蒜鸟「布局」里加一个「电脑屏幕」模块（和加触控板一样），放好位置。
2. 手机和电脑要扫码绑定过局域网、连在同一个网络里。画面只走局域网，只连蓝牙时看不到画面。
3. 手机上点「电脑屏幕」右上角的「⛶」进全屏；侧栏里的「返回主页」回到原来的布局。

转动手机就在竖屏、横屏之间切换：竖屏时画面在上面，下面放语音条和键鼠条；横屏时画面在中间，工具浮在两边。两个方向的位置、大小、收没收起各记各的，转过去就挪到那个方向记住的地方，录音、按着的 Ctrl 都不会断。

## 点画面

| 手势 | 自然触控（默认） | 精密鼠标 |
|---|---|---|
| 单指点 | 左键，点在手指的位置 | 左键，点在箭头的位置 |
| 单指滑 | 滚轮 | 移动箭头 |
| 长按再拖 | 按住左键拖（选文字、拖窗口、拖文件） | 用键鼠条的「按住」 |
| 双指点 | 右键 | 用键鼠条的「右键」 |
| 双指上下 | 滚轮 | 滚轮 |
| 双指张开、捏拢 | 放大、缩小画面（只是手机上看，电脑不变） | 同左 |
| 双指横着划 | 切换应用 | — |
| 双指按住不动 | 打开键鼠条的按键 | — |

小米手机：三指会被系统截屏抢走，所以都用双指；屏幕左右边缘往里划是系统的「返回」。

## 悬浮球

- 点一下打开一圈按钮，点了里面的按钮那一圈自己收起。按住悬浮球能拖，松手贴到最近的一条边（上下左右都行），那一圈朝屏幕中间打开。
- 双击悬浮球：两条（语音、键鼠）一起收成小把手；再双击一起展开。
- 默认 8 个位置：**语音、键鼠、精密鼠标**（这三个固定，只能换位置）、切换应用、微信截图、Alt+F4、Alt+E，还空着一个。
- 「语音」「键鼠」：点一下把那条工具显示出来，再点一下把它藏起来。
- 「精密鼠标」：进精密模式，按钮变成「自然触控」，再点一下退回来。
- 「切换应用」：出现「上一个 / 下一个 / 确定 / 取消」，就像按住 Alt 连按 Tab；10 秒不动自动取消。
- 「微信截图」：发 Alt+A，然后在画面上拖一个框（或者点起点再点终点），Esc 取消。电脑上微信要开着，截图快捷键是 Alt+A。
- 「Alt+F4」会先问一下再发，免得误关窗口（竖屏按键页上的 Alt+F4 也一样）。
- 「发图片」：先用手机自己截屏，再点它，弹出手机自带的选文件，最近的截图在最上面；选一张或几张就发到电脑「下载\蒜鸟」。只发一张图片时还会放进电脑剪贴板，到微信、AI 对话框里 Ctrl+V 就行。和主页「⋯ → 发文件到电脑」是同一个功能。

## 语音条

- **点按开始说话**：点一下开始，再点一下结束，说的话打到电脑光标的地方。录音时按钮变红。
- **键盘输入**：用手机输入法打字（九键、26 键都行），选好字点发送。
- **编辑▾**：展开一排改字的键（退格、空格、方向、大小写、回车），多了自动换行；键盘里还有没发出去的字时，点它直接打开键盘接着改。
- **快捷发送▾**：展开你存好的常用话（和「编辑▾」一次只开一个）。
  - 点一下：这段字打进电脑当前的输入框，默认不按回车；新建、修改时勾「打完按回车」的会直接发出去，按钮上带「⏎」。
  - 「＋ 新建」：填名字（按钮上显示）和要打的字。存在电脑上（布局里的「远程快捷键」页），电脑上也能改。别存密码。
  - 按住一条再拖：排顺序；按住不动再松手：改、往前挪、挪到最前、删除。
- 点标题「语音」：收成一个小把手，还在屏幕上；点小把手展开。标题和小把手都能按住拖。录音时收起，小把手变红、写着「录音中」，录音不断。

## 键鼠条

- **左键、右键、滚↑、滚↓**：精密鼠标时点在箭头的位置；自然触控时点在电脑鼠标现在的位置（上一次手指点的地方）。
- **按住**：精密鼠标时按住左键不放，移动箭头来拖，再点「松开」。自然触控时点它会先切到精密鼠标。
- **按键▾**：展开 Ctrl、Shift、Alt、Win 和常用键（退格、删除、方向、回车、Esc、全选、复制、粘贴、撤销、截屏），多了自动换行。
- **Ctrl / Shift / Alt / Win**：点一下是「带一次」（下一次点击或按键带上它，用完自动松开），再点一下锁住（一直按着，比如 Ctrl 锁住以后连点几个文件多选），再点一下松开。按着的时候画面顶上有提示；10 秒没用、断线、退出全屏、蒜鸟退到后台都会自动松开。
- 点标题「键鼠」收成小把手，和语音条一样。
- 两条都展开、位置又挨着时，会自动上下叠开（打开「竖条」时左右并排），不互相盖住；收起时各回各的小把手。

## 侧栏

右边那根小竖条：点一下展开，点里面任何一项做完就自己收起（只能点，从边上往里划是系统的「返回」）。展开时不挡画面：横屏时塞在画面右边的空白里（空白太窄、或者开着「铺满屏幕」时才盖在画面上），画面不动；竖屏时在画面下面。语音条、键鼠条、侧栏的按钮之间点空了也不会点到电脑。

- **只看画面**：不往电脑发触控，随便缩放、拖着看；再点一下恢复。
- **铺满屏幕**：画面占满整个手机屏幕，边上会裁掉一些（竖屏时裁得多）；再点一下回到完整显示。
- **锁定方向**：不跟着手机转；再点一下解锁。
- **闲时半透明**：语音条、键鼠条 3 秒没碰就变半透明，手一碰马上恢复（录音时、弹出块开着时不变）。
- **竖条**：两条都竖着排，适合塞进横屏两边的空白；编辑键、快捷发送、Ctrl 这些从条旁边弹出一块，点别处收回。再点一下变回横条。
- **恢复大小**（画面放大以后复原）、**调整布局**、**鼠标样式**（精密鼠标的箭头）、**操作说明**、**语音设置**（本地识别快 / 更准、系统引擎、边说边打字，和主页「⋯」里的一样）、**返回主页**。
- 下面的「我的按钮」：在调整布局里自己加的。

## 调整布局

侧栏里点「调整布局」，顶上出现一条蓝色的栏，所有工具都摊开：

- **挪位置、改大小**：拖语音条、键鼠条的标题挪位置，拉右下角的蓝点改大小；拖悬浮球换地方。位置和大小只改当前方向（竖屏、横屏分开调）。
- **拿掉**：点按钮右上角的「−」。悬浮球里带「锁」的三个拿不掉，只能拖着换位置。
- **排顺序**：按住按钮拖到同一排的别的位置；悬浮球里拖到别的位置就是两个换一下。
- **点一个按钮**：往前挪、挪到最前、移到…（悬浮球、语音条、键鼠条、侧栏）、换成别的、改热键、拿掉。
- **点「＋」或悬浮球的空位**：从按钮库里选——手机这边的动作、电脑上的热键、新建热键、新建常用文本、基础键。
- **一个按钮只放一个地方**：选了已经放在别处的，就是把它搬过来，按钮库里会标出它现在在哪。退格、方向这些基础键例外，语音条和键鼠条可以各放一个。
- 新建的热键、常用文本存在电脑上（布局里的「远程快捷键」页），电脑上的「映射」里也能改；双击、长按、一串动作到电脑上配。
- **完成**：发给电脑，电脑确认了才算保存，没确认会提示。**取消**：这次改的都不要。**恢复默认**：回到默认的样子（建过的热键还留在电脑上）。

电脑上的蒜鸟是旧版的话，点「调整布局」会提示先更新电脑端。

## 在电脑上改

电脑上的蒜鸟「布局」页，页面标签最后有「远程工作台」：悬浮球（8 个位置，前 3 个固定）、语音条的快捷发送和编辑键、键鼠条的按键、侧栏「我的按钮」，放什么、什么顺序都能在这里改。

- 按住一个按钮拖：同一排里排顺序，拖到别的排就是挪过去，悬浮球里拖到别的格子是两个换一下。
- 点一个按钮：往前挪、移到别处、换成别的、改映射、拿掉。
- 「＋」：从按钮库里加；最上面的「新建热键」可以点「录制」直接在键盘上按出组合键（和「映射」页的录制一样），「新建常用文本」写一段字、可以选打完按回车。
- 工作台用的热键、快捷发送存在电脑上，但不占你自己的页面（布局里看不到那一页）；从工作台拿掉的，电脑会一起删掉。
- 位置和大小还是在手机上拖。改了自动保存，手机马上跟着变，Ctrl+Z 撤销。

在电脑上删掉一个工作台正用着的按键，工作台里的它会跟着拿掉，不会挡着别的修改保存。

## 遇到问题

- **觉得 Ctrl 之类还按着**：再点一下那个键让它松开；Wi-Fi 断了、电脑暂停按键时，电脑会自己全部松开并告诉手机。还不行就「返回主页」再进来。
- **点了「完成」一直没保存**：看手机是不是连着局域网，电脑上的蒜鸟是不是同一个开发版。
- **老是显示局域网断了**：先看电脑自己的网络——电脑断网（Wi-Fi 掉线、睡眠）时画面上会写「电脑的网络断了，正在等它恢复」，恢复后手机几秒内自己连回来。电脑能插网线最好；用 Wi-Fi 的话把无线网卡的「允许计算机关闭此设备以节约电源」关掉。
- **竖屏上下有空白**：电脑屏幕扁、手机竖着窄，画面完整显示就会留空，空白里正好放工具。想看大一点就横过来，或者用「铺满屏幕」。
- **截图框选没反应**：先确认电脑上那个截图软件开着、快捷键对得上（微信 Alt+A、QQ Ctrl+Alt+A、系统 Win+Shift+S）。
